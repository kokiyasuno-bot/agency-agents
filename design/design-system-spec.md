# デザインシステム最小仕様（v1.0）

## 0. 目的と適用範囲
- 本仕様は、プロダクトUIの一貫性を担保するための**最小構成**を定義する。
- 対象は Web UI（一覧・編集・検索結果）とし、モバイル〜デスクトップのレスポンシブ表示に適用する。

---

## 1. タイポグラフィ階層と余白ルール

### 1.1 タイポグラフィ階層
| 区分 | トークン名 | 用途 | サイズ / 行間 | 太さ | 備考 |
|---|---|---|---|---|---|
| 見出し（大） | `text.heading.lg` | 画面タイトル | 32px / 40px | 700 | 1画面に1つまで推奨 |
| 見出し（中） | `text.heading.md` | セクション見出し | 24px / 32px | 700 | カード見出し等 |
| 見出し（小） | `text.heading.sm` | サブ見出し | 20px / 28px | 600 | ネスト深度を抑制 |
| 本文（標準） | `text.body.md` | 通常本文 | 16px / 24px | 400 | 基本本文サイズ |
| 本文（補足） | `text.body.sm` | キャプション寄り本文 | 14px / 20px | 400 | 表注記など |
| 補助情報 | `text.meta.xs` | 補助ラベル・時刻 | 12px / 16px | 500 | 可読性維持のため最小 |

### 1.2 余白ルール（8pxベース）
- スペーシングは `4, 8, 12, 16, 24, 32, 40, 48` のスケールで運用する。
- 基本ルール:
  - セクション間: `32px`
  - コンポーネント群間: `24px`
  - 要素間（通常）: `16px`
  - ラベルと入力欄: `8px`
  - アイコンとテキスト: `8px`（狭いUIでは`4px`まで許容）
- 余白は原則トークン化し、固定値の直書きを避ける。

## 2. カラートークン最小セット

### 2.1 トークン定義
| カテゴリ | トークン名 | 値（HEX） | 用途 |
|---|---|---|---|
| 背景 | `color.bg.base` | `#FFFFFF` | ページ背景 |
| 背景（副） | `color.bg.subtle` | `#F7F8FA` | カード/入力欄背景 |
| 境界線 | `color.border.default` | `#D9DEE5` | 罫線・区切り線 |
| 境界線（強） | `color.border.strong` | `#B8C0CC` | 強調枠 |
| アクセント | `color.accent.primary` | `#2563EB` | 主操作・リンク |
| アクセント（hover） | `color.accent.primaryHover` | `#1D4ED8` | hover状態 |
| 警告 | `color.alert.warning` | `#D97706` | 警告文・注意アイコン |
| 警告背景 | `color.alert.warningBg` | `#FFF7ED` | 警告バナー背景 |
| 文字（主） | `color.text.primary` | `#111827` | 主本文 |
| 文字（補助） | `color.text.secondary` | `#4B5563` | 補足文 |

### 2.2 運用ルール
- 1画面で使うアクセント色は原則1系統（`accent.primary`）に統一。
- 警告は意味付けのため `alert.warning` 系のみを使用し、通常の強調用途で流用しない。
- 背景と文字のコントラストは WCAG AA（通常テキスト 4.5:1 以上）を満たす。

## 3. コンポーネント仕様（カード・ボタン・入力欄）

### 3.1 カード
- 寸法:
  - 最小高さ: `120px`
  - 内側余白: `16px`（モバイル）/`24px`（デスクトップ）
  - 角丸: `12px`
  - 境界線: `1px solid color.border.default`
- 状態:
  - default: 背景 `bg.base`
  - hover: 背景 `bg.subtle`、影 `0 4px 12px rgba(0,0,0,0.06)`
  - focus-within: `2px` のフォーカスリング（`accent.primary` 20%）
  - disabled: 不可状態コンテンツは `text.secondary` にし、操作部を無効化

### 3.2 ボタン
- 共通:
  - 高さ: `40px`（標準）、`32px`（小）
  - 横余白: `16px`
  - 角丸: `10px`
  - フォント: `text.body.sm`、太さ `600`
- Primary:
  - default: 背景 `accent.primary`、文字 `#FFFFFF`
  - hover: 背景 `accent.primaryHover`
  - focus: `2px` 外側リング（`accent.primary` 30%）
  - disabled: 背景 `#93C5FD`、文字 `#E5E7EB`、カーソル不可
- Secondary:
  - default: 背景 `#FFFFFF`、文字 `text.primary`、枠 `border.default`
  - hover: 背景 `bg.subtle`
  - focus/disabled は Primary のガイドに準拠

### 3.3 入力欄（テキスト）
- 寸法:
  - 高さ: `40px`
  - 内側余白: 左右 `12px`
  - 角丸: `10px`
  - 枠: `1px solid border.default`
- 状態:
  - default: 背景 `#FFFFFF`
  - hover: 枠 `border.strong`
  - focus: 枠 `accent.primary` + `2px` フォーカスリング
  - disabled: 背景 `#F3F4F6`、文字 `#9CA3AF`、枠 `#E5E7EB`
- 補足:
  - エラー状態（任意拡張）を追加する場合は warning 系とは分離し、`danger` トークンを別途定義する。

## 4. ブレークポイント（2段階以上）

| 名前 | 条件 | 用途指針 |
|---|---|---|
| `bp.mobile` | `< 768px` | 1カラム、余白 `16px` |
| `bp.tablet` | `768px - 1023px` | 2カラム許容、余白 `24px` |
| `bp.desktop` | `>= 1024px` | 12カラムグリッド、余白 `32px` |

運用ルール:
- タイポは `mobile` で1段階小さくしても良いが、本文16pxを下限目安とする。
- 一覧表は `mobile` でカード化、`desktop` で表形式を優先する。

## 5. デザインレビュー観点チェックリスト（代表3画面）

### 5.1 一覧画面
- [ ] 見出し階層が `heading.lg -> heading.md -> body` の順で破綻していない。
- [ ] カード間余白が16/24/32スケールに収まっている。
- [ ] primary操作（例: 新規作成）が1つに絞られている。
- [ ] hover/focus時にカードとボタンの状態差が視認できる。
- [ ] `mobile` で情報密度が過多にならず、主要情報がファーストビューに収まる。

### 5.2 編集画面
- [ ] ラベル・入力欄間の余白が8px、項目ブロック間が16px以上で統一されている。
- [ ] 入力欄の focus/disabled 状態が仕様通り。
- [ ] 警告表示は `alert.warning` 系のみ利用し、意味が一貫している。
- [ ] 保存/キャンセルの優先度がボタンスタイル（Primary/Secondary）に反映されている。
- [ ] `tablet` 以上で2カラム化しても読み順・操作順が自然。

### 5.3 検索結果画面
- [ ] 検索条件、件数、結果リストの情報階層が明確。
- [ ] 結果0件時の空状態（Empty State）に補助情報と次アクションがある。
- [ ] ハイライトやフィルタ表示でアクセント色を過剰利用していない。
- [ ] ページネーション/無限スクロールの操作要素がフォーカス可能。
- [ ] `mobile` でフィルタUIが折りたたみ等で操作可能、`desktop` で常時表示が破綻しない。

## 6. 運用メモ
- 仕様変更時は「トークン追加理由」「影響コンポーネント」「レスポンシブ影響」をセットで記録する。
- デザインレビューでは本書のチェックリストをテンプレートとして利用し、画面ごとの差分のみ追記する。
